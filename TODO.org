This project demonstrates how to build binary wheels for Python
packages that incorporate LAPACK- and BLAS-dependent Fortran 77 code.

To read this you'll need basic knowlege of [[https://packaging.python.org/en/latest/][Python packaging]], including
use of ~pip~, and terms like "wheel" and "sdist".

** Requirements

The build setup should:
  - allow end-users to run  ~pip install --only-binary :all: f77ex~ (where ~f77ex~ is the package name) to install the package
  - allow building from sdist using user-configurable compilers and LAPACK&BLAS libraries
  - support editable installs

** Supported platforms

The setup described here can build wheels for the following CPython platforms:

  | PEP 11 target triple | PEP 11 Tier | Platform tags                               |
  |----------------------+-------------+---------------------------------------------|
  |                      |             | macosx_14_0_arm64                           |
  |                      |             | manylinux_2_28_x86_64, musllinux_1_2_x86_64 |
  |                      |             | win_amd64                                   |
  |                      |             |                                             |


There's one PEP 11 Tier one platform that's *not* supported, namely
~i686-pc-windows-msvc~.  NumPy 2.4.4 (released March 2026) has binary
wheels for this platform, and it may not be very difficult to get this
to work too.

** Build steps

The wheel building is done by cibuildwheel.  The customizations for bundling OpenBLAS are:

1. Pre-build, copy files from scipy_openblas32

   - install scipy_openblas32 using pip
   - copy OpenBLAS libraries into a known location for building
   - copy OpenBLAS licenses into a known location to be added to the wheel

2. During build, Fortran source is built with prefix ~SCIPY_~ added to all LAPACK and BLAS functions; e.g., ~DGETRF~ becomes ~SCIPY_DGETRF~

3. Post-build wheel repair is given access to all necessary libraries
